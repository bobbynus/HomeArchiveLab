# Home Archive Lab

Настольная программа для домашнего архива фото и видео (Windows, Python + Qt).

## Возможности

| Раздел | Что умеет |
|---|---|
| **Медиатека** | Сетка миниатюр (фото, HEIC, видео), фильтр Фото/Видео, поиск, сортировка, масштаб, панель информации о файле (разрешение, камера, объектив, выдержка, ISO, GPS, кодек, длительность, битрейт). Delete — в корзину. |
| **Сортировка** | Раскладка по папкам по дате съёмки (EXIF / метаданные видео), типу, камере, расширению или своему шаблону. Переименование по дате. Копирование или перемещение. Предпросмотр плана перед выполнением. |
| **Дубликаты** | Точные копии (хэш содержимого) и похожие фото (перцептивный хэш — находит пересжатые и уменьшенные копии). Автовыбор лучшего файла, удаление в корзину Windows. |
| **Редактор** | Интерактивный кроп с пропорциями, поворот, отражение, форма (круг, овал, скруглённые углы), пресеты соцсетей, вписывание с полями / на размытом фоне, живой предпросмотр. Работает и с видео (кроп, размер, обрезка по времени, без звука). |
| **Пакетная обработка** | Одни настройки на сотни файлов в несколько потоков. Режим «Несколько соцсетей» — сразу экспорт под все отмеченные форматы, каждый в свою папку. |
| **Апскейл (GPU)** | Real-ESRGAN через Vulkan (NVIDIA / AMD / Intel), ×2/×3/×4, модели для фото, рисунков и видео. Устанавливается одной кнопкой. Сравнение «до/после» со шторкой. Без движка — CPU-режим. |
| **Метаданные** | Все теги файла, редактирование автора, копирайта, описания, камеры, даты съёмки. Удаление всех метаданных или только GPS (JPEG — без пересжатия). |
| **Сеть** | Встроенный сервер: открываете адрес или QR-код на телефоне — смотрите, скачиваете и загружаете фото через браузер. PIN-защита. Автопоиск других ПК с Home Archive Lab, просмотр их архива, скачивание и отправка файлов. |

Пресеты: Instagram, TikTok, YouTube, VK, Telegram, Facebook, X, LinkedIn, Pinterest, WhatsApp, печать, экраны.

## Запуск

Дважды щёлкните **`Home Archive Lab.bat`** — при первом запуске он создаст окружение и установит зависимости.

Вручную:

```bash
py -3.11 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\pythonw run.pyw
```

Для видео нужен **ffmpeg** в PATH (`winget install ffmpeg`) или `ffmpeg.exe` + `ffprobe.exe` в `%APPDATA%\HomeArchiveLab\tools`.

Настройки, кэш миниатюр и Real-ESRGAN хранятся в `%APPDATA%\HomeArchiveLab`.
